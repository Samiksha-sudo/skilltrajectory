# SkillTrajectory

A full-stack web app with an Express API and a Next.js front end.

> **Status: work in progress.**

## Tech stack

- **Back end:** Node.js, Express 5, Sequelize, MySQL
- **Front end:** Next.js 16

## Structure

```
backend/    Express + Sequelize API
frontend/   Next.js app
```

## Getting started

1. Install and start MySQL, then create a database.
2. Configure the back end with your own database credentials through environment variables. Do not commit credentials.
3. Run each part:

   ```bash
   cd backend && npm install && npm start
   cd frontend && npm install && npm run dev
   ```
